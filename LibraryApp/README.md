# LibraryApp

Консольное приложение на C# (.NET 8) для учёта книг в библиотеке:
добавление книг, выдача, возврат, поиск по Id. Демонстрирует отладку
в Visual Studio, исправление логических ошибок, инспекцию кода и
документирование результатов тестирования.

## Запуск
```bash
dotnet run --project LibraryApp
```

## Структура
- `Book.cs` — модель книги;
- `Library.cs` — бизнес-логика (AddBook, BorrowBook, ReturnBook, FindBook);
- `Program.cs` — демонстрация всех сценариев, включая граничные случаи;
- `TEST_REPORT.md` — отчёт о тестировании.
